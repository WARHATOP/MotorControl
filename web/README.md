# 🎃 Halloween Logic — тестовая схема на React Flow

Небольшой прототип редактора логических схем на [React Flow](https://reactflow.dev)
(`@xyflow/react`) в хэллоуинском оформлении. Сделан как проба пера перед тем,
как строить полноценный редактор схемы управления мотором.

## Запуск

```bash
cd web
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + прод-сборка в dist/
```

## Что внутри

Три типа узлов (`src/nodes/`):

| Узел     | Тип      | Хендлы                     | Поведение                                  |
| -------- | -------- | -------------------------- | ------------------------------------------ |
| Кнопка   | `button` | выход `out`                | клик по надгробию переключает 0 ↔ 1        |
| ИЛИ      | `or`     | входы `a`, `b`, выход `out`| 1, если истинен хотя бы один вход           |
| Фонарь   | `lamp`   | вход `in`                  | светится и мерцает, когда на входе 1        |

Стартовая схема: две кнопки → «ИЛИ» → фонарь.

## Как считается сигнал

`src/logic.ts` — единственное место с логикой. Значения узлов не хранятся в
состоянии: `evaluate()` пересчитывает их из графа (узлы + рёбра) на каждый
рендер, а `App.tsx` подмешивает результат в `data.value` перед отрисовкой.
Состояние в `useNodesState` держит только то, что задаёт пользователь:
позиции узлов и положение переключателей.

Пересчёт — итеративная релаксация до стабилизации, не больше `nodes.length + 1`
проходов. Для ациклической схемы этого всегда хватает, а случайно собранная
обратная связь не подвесит вычисление.

Активные рёбра подсвечиваются оранжевым и анимируются — видно, куда идёт сигнал.

## Что умеет UI

- клик по кнопке-надгробию — переключение сигнала;
- перетаскивание узлов, зум, мини-карта, контролы;
- новые связи протягиваются мышкой от кружка-хендла (петли `source === target`
  запрещены в `isValidConnection`);
- панель слева: добавление узлов любого типа, сброс к исходной схеме,
  счётчик горящих фонарей.
